# SNITE

* **CREATOR:** @MEFAMEX
* **DATE:** 2026-05-24
* **FRAMEWORK:** React + Vite

## WHAT TO DO

Bir minigame, verilen başlangıç noktalarını kare kutucuklu haritaya göre uzatarak boşluk kalmayacak şekilde tamamlamaya çalışın. Her bir başlangıç noktası, farklı bir renkte olacak. Tüm kutucuklar doldurulduğunda oyun kazanılır.




## SETUP - BUILD - RUN

```bash
pnpm create vite@latest snite  --template react
cd snite
pnpm install

pnpm run build

pnpm run dev
```
